# GitHub Implementations

Open-source implementations and frameworks relevant to Agentic AI, agent evaluation, verification, monitoring, and reliable tool use.

## 1. AgentBench

**Repository:** THUDM/AgentBench

AgentBench provides an evaluation framework for assessing large language models as agents across multiple environments. It is useful for studying agent performance and failure modes.

[GitHub Repository](https://github.com/THUDM/AgentBench)

## 2. LangGraph

**Repository:** langchain-ai/langgraph

LangGraph provides graph-based orchestration for stateful agent workflows. Its explicit workflow structure makes it useful for implementing intermediate verification and checkpoint stages.

[GitHub Repository](https://github.com/langchain-ai/langgraph)

## 3. AutoGen

**Repository:** microsoft/autogen

AutoGen provides an open-source framework for developing applications using multiple interacting AI agents. It can be used to experiment with agent collaboration and verification strategies.

[GitHub Repository](https://github.com/microsoft/autogen)

## 4. OpenAI Evals

**Repository:** openai/evals

OpenAI Evals is a framework for evaluating AI models and systems using custom evaluation criteria and test cases. It is relevant for systematic evaluation and detection of model failures.

[GitHub Repository](https://github.com/openai/evals)

## 5. DeepEval

**Repository:** confident-ai/deepeval

DeepEval is an open-source evaluation framework for LLM applications. It provides evaluation metrics and testing mechanisms that can help identify hallucination, correctness, and other reliability problems.

[GitHub Repository](https://github.com/confident-ai/deepeval)
