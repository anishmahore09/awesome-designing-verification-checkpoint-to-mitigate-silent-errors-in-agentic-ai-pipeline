# Tutorials and Learning Resources

Authoritative resources for learning about Agentic AI, LLM evaluation, reliability, and AI agent development.

## 1. Hugging Face — Agents Course

A practical course covering AI agents, tools, agent frameworks, and building agentic systems.

[Agents Course](https://huggingface.co/learn/agents-course)

## 2. LangGraph Documentation

Official documentation covering graph-based agent workflows, state management, persistence, human-in-the-loop workflows, and agent orchestration.

[LangGraph Documentation](https://docs.langchain.com/oss/python/langgraph/)

## 3. OpenAI — Evaluations

Official documentation explaining how to evaluate AI systems using evaluation datasets, graders, and testing workflows.

[OpenAI Evaluation Guide](https://platform.openai.com/docs/guides/evals)

## 4. Anthropic — Building Effective Agents

A practical guide explaining common agent architectures, workflows, tool use, and design considerations for building effective AI agents.

[Building Effective Agents](https://www.anthropic.com/research/building-effective-agents)

## 5. Stanford CS25 — Transformers United

Stanford's seminar series provides lectures and discussions from researchers working on Transformers and modern language-model systems. It is useful for understanding the foundations behind current agentic AI systems.

[Stanford CS25](https://web.stanford.edu/class/cs25/)
